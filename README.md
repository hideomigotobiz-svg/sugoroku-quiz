# すごろくクイズ

スマホ1台を2〜6人で回して遊ぶ、すごろく形式のクイズ。

**遊ぶ**: https://hideomigotobiz-svg.github.io/sugoroku-quiz/

スマホで開いて「ホーム画面に追加」すると、アプリのように全画面で起動し、ネットがなくても遊べる。

- iPhone（Safari）: 共有ボタン →「ホーム画面に追加」
- Android（Chrome）: メニュー →「ホーム画面に追加」／「アプリをインストール」

このリポジトリはビルド済みファイルの置き場。ソースと問題DBは別リポジトリ（非公開）の `mobile/` と `scripts/build_mobile.py`。
